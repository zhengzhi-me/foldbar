# FoldBar

为 macOS 菜单栏留出空间。把不常用的图标折叠起来，需要时再展开。

[下载 FoldBar](https://github.com/zhengzhi-me/foldbar/releases)

## 功能

- **适配 macOS 27**：直接在原生菜单栏中隐藏与展开，不使用悬浮窗，也不需要录屏权限。
- **三段式整理**：常显示、普通隐藏和持续隐藏。按住 ⌘ 并拖动状态图标来调整分区。
- **快速操作**：左键展开或折叠；折叠时右键打开设置与退出菜单，展开时右键切换持续隐藏区。
- **原生设置**：登录时启动、隐藏 Dock 图标、延时自动折叠、全局快捷键和按需检查更新。

## 安装

下载适用于 Apple Silicon 的压缩包，解压并将 FoldBar 拖到「应用程序」。启动前退出 Hidden Bar 或其他菜单栏整理工具。macOS 27 上需要「辅助功能」权限来识别图标分区。

macOS 27 上，隐藏按应用生效。同一应用的多个图标会一起隐藏；折叠时，专注模式和正在播放等部分系统状态项可能暂时不显示。当前预发行包采用本地签名，更新可能需要重新授权。
